## Task Manager App

### Описание
Task Manager — это веб-приложение для управления задачами.

### Функционал
* Регистрация и авторизация пользователей
* Создание, редактирование и удаление задач
* Управление статусами задач
* Фильтр, поиск и сортировка

### Стек технологий
#### Клиентская часть
* ReactJS + TypeScript
* Redux Toolkit
* Axios
* SCSS + CSS переменные
* Webpack

#### Серверная часть
* Koa
* JWT аутентификация
* REST API
* Раздача статической сборки клиентской части

### Запуск приложения
```
npm install
npm run build:client
npm run start:server
```
Приложение будет доступно по адресу: http://localhost:4000

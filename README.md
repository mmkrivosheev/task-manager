## Task Manager App

### Описание
Task Manager — это веб-приложение для управления задачами.<br>
Развернутый проект доступен по адресу: https://task-manager-htg3.onrender.com

### Функционал
* Регистрация и авторизация пользователей
* Создание, редактирование и удаление задач
* Управление статусами задач
* Фильтр и поиск по задачам

### Стек технологий
#### Клиентская часть
* ReactJS + TypeScript
* Redux Toolkit
* Axios
* SCSS + CSS переменные
* Webpack

#### Серверная часть
* Koa
* JWT аутентификация
* REST API
* Раздача сборки клиентской части

### Запуск приложения
```
npm install
npm run build:client
npm run start:server
```
Приложение будет доступно по адресу: http://localhost:4000
